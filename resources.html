Getting started

Your first local benchmark.

Set up the client, connect a model runtime and measure your own machine.

Download for Windows
01

Open Aetherion Studio

Download the Windows executable. Sign in with your Aetherion account and active license. New accounts require a signed license key.

02

Connect your model runtime

Start Ollama and install a model that fits your memory. Refresh the model list in the client. For GGUF, configure a compatible runtime and choose your model folder.

03

Run one workload

Select an installed model and a task category. Start the benchmark in the client, then review latency, throughput and task validation together.

04

Keep the comparison useful

Save the JSON report. Compare runs using the same category and settings; model speed changes with hardware, context length and runtime configuration.
