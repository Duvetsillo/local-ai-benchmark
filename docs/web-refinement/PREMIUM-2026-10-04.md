# Aetherion homepage refinement

The incumbent orbital brand, cold blue palette, product copy, routes, benchmark criteria, consent and mail-draft workflow are preserved. This is an editorial refinement of the existing homepage, not a frontend/backend migration.

The hero now presents the implemented Qt client in a manually controlled three-view gallery. Workspace uses real local hardware/models; Models and Benchmark use temporary demonstration data and are labeled accordingly. Satoshi weights 400/500/700 are self-hosted from the official Fontshare API. Vendor GSAP/ScrollTrigger 3.13.0 assets retain their embedded license notices and use no CDN at runtime.

The seeded gpt-taste direction selected Editorial Split, Satoshi, a marquee, a carousel and horizontal selectors, plus scroll pinning and a text reveal. The carousel contains real application captures rather than invented testimonials. The supported-features marquee is pausable, pauses on hover or a hidden tab, and becomes a static scrollable row with reduced motion. A desktop-only workflow pin plus readable opacity reveal is reverted on keyboard input, viewport changes and reduced motion. Content remains visible without GSAP or JavaScript.

Typography, spacing, focus, vector arrows, form controls, browser surfaces, responsive sections, cookie preferences and download composition were improved. The web download now contains the verified Qt Windows executable (52.6 MiB); both homepage and Resources link to it. GGUF packaging requirements are explicit in FAQ and setup instructions.

Validation: 63 Python tests pass, tsc --noEmit and node --check pass. Three gallery views, five task categories, FAQ, mobile menu/Escape, required form feedback and download HEAD were checked in the browser. Layout checks pass at 375, 390, 768, 1024, 1440 and 1920 px. Reduced-motion and keyboard handling revert all ScrollTriggers; no browser errors were reported. Desktop/mobile captures are included.

The Impeccable detector was run once. Its tiny brand tagline finding was fixed to 11px, and scroll text starts at .75 opacity to retain readable contrast. The marquee is an intentional exception requested by the invoked gpt-taste skill, with user controls and reduced-motion handling. Other static findings referenced legacy intro/grid/glow rules that do not render on this homepage; new surface elevation uses a neutral offset shadow without a hairline border. No claim of a complete WCAG audit is made.
