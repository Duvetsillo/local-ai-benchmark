# Ultron — integración con Obsidian
## Estado documentado

El README del 6 de septiembre registra acceso directo a archivos, sincronización de memoria en proceso y API REST pendiente. En esta sesión se comprobó la ubicación del vault activo; eso no acredita que Ultron tenga una API instalada ni sincronización automática operativa.

## Objetivos del registro

Lectura y escritura de notas, búsqueda y resumen, clasificación por etiquetas, índices automáticos y una futura integración REST. Las casillas originales permanecen sin cerrar: no convertir una tarea de prueba en implementación.
