# Skills de diseño instaladas para Codex
## Instalación solicitada y completada

El usuario solicitó los paquetes de Emil Kowalski, Impeccable y Leonxlnx/taste-skill. Se instalaron globalmente para Codex y se verificaron los archivos y su detección.

| Paquete | Resultado registrado |
| --- | --- |
| Emil Kowalski | 14 skills de diseño, UI y animación |
| Impeccable | Skill, scripts y motor Windows instalados |
| Taste | 13 skills de diseño visual y frontend |

## Uso y alcance

La instalación posterior no significa que esas guías se hayan aplicado ya a Studio 03. Varias están orientadas a web, CSS o React; antes de usarlas en Tkinter hay que adaptar lo pertinente al stack real. No forzar una migración de framework por una recomendación de skill.

Impeccable quedó instalado sin hooks de ciclo de vida. Su inicialización de contexto no se ejecutó en esta sesión. Caveman y UI/UX Pro Max tienen estados distintos, desarrollados en [[Proyecto Aetherion/08_Herramientas_Diseno/02_Caveman_y_UIUX]].
