# Aetherion — mapa del proyecto
Aetherion compara modelos locales bajo contexto de equipo y ejecución. La revisión de cliente documentada más reciente es Studio 03. Este mapa organiza el conocimiento por áreas; cada área contiene procesos, evidencia y fuentes.

- [[Proyecto Aetherion/01_Arquitectura/00_Mapa_Arquitectura|Arquitectura y evaluación]] — Motor, proveedores, hardware, validadores y contratos de resultados.
- [[Proyecto Aetherion/02_Cliente/00_Mapa_Cliente|Cliente y experiencia]] — Pantallas, interacción, Studio 03 y evolución del sistema visual.
