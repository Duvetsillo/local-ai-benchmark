A little more clarity.

Does the benchmark run in my browser?

No. The website explains the workflow; the Windows client runs the benchmark against your configured model runtime.

Which models can I benchmark?

The Windows download runs installed models served by Ollama. GGUF requires a source installation with llama-cpp-python, or a build that bundles that runtime. Model availability and memory requirements depend on your setup.

What should I compare in a report?

Read time to first token, tokens per second and task validation together. Use the same task, model settings and hardware conditions for a useful comparison.

Do I need an account or internet access?

The client requires an Aetherion account and active license. Model inference can run locally; account sign-in and license verification use the account service.
